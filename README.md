# React + TDD Technical Challenge

Self-paced bootcamp on how to face a React + TypeScript technical interview (TDD, scoping, pure domain vs UI).

## Quick start

```bash
pnpm install
pnpm dev
```

Open [http://localhost:5173/bootcamp](http://localhost:5173/bootcamp).

Requires **Node 22** and **pnpm@11.18.0** (`packageManager` field).

## Tracks

| Track | Duration | Goal |
|-------|----------|------|
| `short` | ~45 min | Hand-solvable interview slice |
| `full` | open-ended | Continue as far as you can |

Do **short** before **full**. Homework is outside the 45-minute talk path — see `WORKSHOP_SCHEDULE.md`.

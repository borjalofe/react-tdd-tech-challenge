# React + TDD Technical Challenge

Self-paced bootcamp on facing a React + TypeScript technical interview (TDD, scoping, pure domain vs UI).

Warehouse explorer kata: grid `mapX`×`mapY`, commands `f`/`b`/`l`/`r`, wrap, immutable `ExplorerState`.

## Quick start

```bash
pnpm install   # Node 22 + pnpm@11.18.0
pnpm dev
```

- Bootcamp: [http://localhost:5173/bootcamp](http://localhost:5173/bootcamp)
- Instructor mode: add `?instructor=1`
- Reference playground: [http://localhost:5173/](http://localhost:5173/) (spoiler — see AGENTS.md)

```bash
pnpm test           # green suite (domain + solutions)
pnpm test:starters  # expected red on unfinished starters
pnpm typecheck
```
